# Coffee Shop Sales Dashboard

An interactive dashboard created to analyze transactional sales data and provide actionable business insights into sales performance and customer purchasing patterns.

### Project Overview
The primary objective of this project is to transform raw sales data into a clear, visual report to identify key trends, peak purchasing times, and top-performing products.

* **Dataset:** [Coffee Shop Sales Dataset](https://mavenanalytics.io/guided-projects/coffee-shop-dashboard)
* **Source:** Maven Analytics

### **Key Areas Explored**
* **Total Sales Performance:** Overall revenue and transaction volume.
* **Sales Trends Over Time:** Performance changes across dates and months.
* **Day & Time Patterns:** Transaction density by day of the week and hour of the day.
* **Product Category Performance:** Top-selling products and categories.
* **Store-Level Performance:** Comparative sales across different store locations.
